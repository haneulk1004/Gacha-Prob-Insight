Gacha Prob Insight (가챠 확률 인사이트)

0. 박스 선택 / 관리

- A박스, B박스처럼 여러 박스를 만들어 각각 다른 아이템 구성과 확률을 관리할 수 있습니다.
- 아래 아이템 테이블은 항상 현재 선택된 박스 기준으로 표시됩니다.

1. 아이템 구성 입력

현재 박스:
- 각 행에 아이템 이름과 가중치(또는 확률)를 입력하세요.
- 가중치는 합이 1이 아니어도 됩니다. 내부에서 정규화하여 확률로 변환합니다.

아이템 이름 가중치 / 확률 행 삭제

예시) 가중치를 1, 2, 3으로 넣으면 내부적으로 전체 합 6을 기준으로 각각 1/6, 2/6, 3/6 확률로 계산합니다.

2. 데이터 시트 연동

2-1. CSV 파일 업로드

- CSV 첫 행은 헤더(열 이름)로 가정합니다.
- 열 이름 예시: name, weight 또는 아이템, 확률
- 이름/가중치 컬럼을 자동으로 찾되, 못 찾으면 1열=이름, 2열=가중치로 처리합니다.

2-2. Google Sheets에서 불러오기 (공개 시트 + API Key 필요)

- Google Sheets 문서가 공개되어 있어야 하고, Google Cloud에서 발급한 API Key가 필요합니다.
- URL 예시: https://docs.google.com/spreadsheets/d/시트ID/edit... 에서 시트ID 부분만 복사해 넣으면 됩니다.
- 범위 예시: Sheet1!A:B (A열=이름, B열=가중치).

3. 뽑기 / 시뮬레이션 설정

(예: 한 유저가 N회 뽑기를 했을 때 기준)
(0이면 시뮬레이션 생략 / 예: 10000 → N회 뽑기를 1만 번 랜덤으로 돌려서 이론값과 비교)

4. 계산

- 가정: 매 회 뽑기마다 독립적으로 한 개의 아이템이 나옵니다 (가챠/랜덤박스에서 같은 아이템이 여러 번 나올 수 있는 구조, 복원추출).
- N, M, 아이템 개수가 너무 크면 시뮬레이션에 시간이 오래 걸릴 수 있어 제한을 둡니다.

5. 결과

아직 계산하지 않았습니다. 위에서 아이템과 N, M을 입력한 후 “확률 계산하기”를 눌러주세요.
