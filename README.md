# Gacha Prob Insight (가챠 확률 인사이트)

**Gacha Prob Insight**는 웹 브라우저에서 바로 실행되는  
**가챠 / 랜덤박스 아이템 확률 분석 도구**입니다.

아이템 구성과 가중치를 직접 입력하거나  
CSV / Google Sheets에서 불러온 뒤, 다음을 계산할 수 있습니다.

- 각 아이템의 **1회 뽑기 확률**
- 유저가 N회 뽑았을 때 각 아이템의 **기대 개수**
- 유저가 N회 뽑았을 때 각 아이템이 **한 번 이상 나올 확률**
- (옵션) N회 뽑기를 M번 시뮬레이션한 **경험적 결과**
- 이론값 vs 시뮬레이션 결과의 **막대 그래프 비교**
